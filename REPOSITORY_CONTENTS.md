# Repository Contents

Complete MuleZero prototype repository containing source code, demo data, database schema, documentation, tests and deployment files.

- `backend/` — FastAPI API, SQLite database layer, graph engine, demo data, iNSIGHTS boundary
- `frontend/` — browser dashboard and Cytoscape.js visualization
- `data/` — synthetic transaction data
- `database/` — PostgreSQL schema
- `docs/` — architecture, iNSIGHTS, problem statement, tech stack, references and GitHub instructions
- `models/` — model notes
- `tests/` — graph-engine tests
- `scripts/` — demo runner
- `Dockerfile`, `docker-compose.yml` — deployment
